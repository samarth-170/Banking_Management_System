# Banking Management System
A simple **Banking Management System** built using **Java**. This console-based application allows users to perform basic banking operations such as creating accounts, depositing money, withdrawing funds, viewing account details, and deleting accounts through a menu-driven interface.
This project was created to practice Java programming concepts, including Object-Oriented Programming (OOP), collections, loops, conditional statements, and user input handling.
---

## Features
- Create a new bank account
- Deposit money into an account
- Withdraw money with balance validation
- View account details
- Delete an existing account
- Prevent duplicate account numbers
- Menu-driven console interface
- In-memory account management using `ArrayList`
---

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Java Collections (`ArrayList`)
- Scanner Class

## How to Use
1. Run the program.
2. Select an option from the menu:
   - Open Account
   - Withdraw Money
   - Deposit Money
   - View Account Details
   - Delete Account
   - Exit
3. Enter the required account information.
4. The application performs the requested banking operation and displays the result.
